📖 Quy tắc thuật toán

Tại thời điểm now, chỉ tính request có timestamp t > now − 60. Timestamp t ≤ now − 60 phải được xóa trước khi đếm.

cutoff = now - 60 while queue[0] <= cutoff: queue.shift() // xóa timestamp cũ if queue.length >= 5: return HTTP_429 queue.push(now) return HTTP_200

Đây là Sliding Window Log, không phải Fixed Window hay Sliding Window Counter. HTTP 429 không được thêm vào queue trong mô phỏng này.
